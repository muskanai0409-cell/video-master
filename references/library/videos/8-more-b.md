# Batch 8-more-b: loops, memes, founder demos and supermemory's own clips (30 entries)

Method note: frames come from exact-seek 16-frame sheets (tile k sits at (k+0.5)·T/16 with T = min(duration, 240), so for the four videos longer than 240s the sheet covers only the first 240s), from hook strips at 0, 0.5, 1.0, 1.5, 2.0 and 2.5s, and from end strips covering the last 4s of each file. Audio was not heard: only its presence and integrated loudness are reported. Moving %, stills and cuts come from each `metrics.json` (cut threshold 0.32, which misses dissolves, morphs, dark cuts and animated layout changes, so 0 cuts means the video looks continuous, not that it is unedited). Views are the bookmarked post's, so a quoted clip carries the quoting post's views.

- **Lessons for her launch films and supermemory videos:**
  1. Make one-idea posts as 3-10s seamless loops with one constant and one variable: the supermemory mark stays in the dock while agent icons bounce through the slot beside it (akothari's dock).
  2. Upgrade the memory lane to twin lanes on the same prompt: token, time and cost counters on both, red notes on stale, re-read and conflicting files, and a compiled result with versions and a forgotten fact struck through. Dhravya's markdown film already has this; it needs type two to three times larger.
  3. Pair each claim with its proof: a 1.5-2s serif claim card, then 5-8s of real UI, three times, then an availability line and the lockup (Claude Science). Show waiting as a calm Thinking pill on texture, not a spinner.
  4. Cold-open on the payoff: the agent recalling something it was told last week, live, before any setup (Dialbot's call, the podcast's trailer).
  5. Run the launch post itself through the product: save it as a memory and have the agent recall it (Tweet Tester scores its own launch tweet).
  6. Roll the headline numbers up from zero in the first half second and keep a run ticker of time, calls and cost on screen (Monid).
  7. In founder talking heads, say the product name and the claim in the first 3s, number the chapters, record near the -14 to -20 LUFS the produced pieces use, proof-read captions, and end on the repo URL or install command. Muskan's Company Brain video got the chapters right and skipped the rest.
  8. Show the MCP install literally in Claude's add-connector dialog (NewWave), and end plugin stories on the list-and-revoke command as the trust shot (Dhravya's changelog).
