**Lessons:**
1. **Anchor the eye, then cut as fast as you like.** LexnLin's orange dot and Claude's arc hold 37-96 cuts/min together, and Keiki's timeline line does the same with zero cuts. For supermemory: one memory node or dot at fixed screen coordinates across every scene.
2. **Follow every claim with proof within ~5s.** Zaro answers "Build an app." with the pipeline UI, and mattyp answers each list item with a full-screen card or screen. In Muskan's changelog, full-screen proof covers only ~8s of 140s.
3. **Show memory as motion, but vary the surface.** Keiki carries nouns along a timeline into the reply; eve draws lines from a memory panel after "days later"; Muse Code's reply cites the client, the date and a teammate. Four supermemory films here (MCP, eve, Keiki, Muse Code) share the save-then-recall relay, and two of them (eve, Muse Code) share the same dark chat-plus-panel layout. Keep the relay and change the visual metaphor.
4. **Make frame 0 move.** Counters (Island, Kyoso), a glyph swap (Testimonial), changing inline icons (Zaro) and a door bursting open (Stan) all change within 0.5s. Held UI opens (Keiki's 2.4s still, Okara, the SMFS chart) are the weakest hooks in the batch.
5. **Readable on a phone beats complete.** Push in until the line that matters fills the frame, as with the typed date in MCP or Zaro's chat input. Muse Code's mono lines, the SMFS tooltips and the Okara page can't be read at ~480px wide. Rebuild UI in vector with large type (her standing rule).
6. **Borrow a ritual or genre, then subvert it with specifics.** iPhone Duo turns Apple's ad grammar into an instalment joke, Stan uses a press conference and a jersey for a hire, the relaunch uses a missing poster, and Pocket puts live UI into a spa scene. A "signing day" for a partner integration is a ready-made supermemory version.
7. **Budget the runtime by chapter.** Cloudflare spends about 20% on intro, 14% on demo, 7% on social proof, 10% on features, 24% on use cases and 24% on outro. Muskan's changelog spends 37% (52s) on six small fixes. Repost your own launch as a chapter-bar breakdown (titouangillet_, rajsinghfirst) for a second wave of views.
8. **End on one action, held 2-3s, and check loudness.** The median final hold is about 2s. The clearest closes put one actionable line on the last card: Muse Code's install command, Kyoso's "Now available" then the URL, Testimonial's start-free button, Zaro's URL pill. The MCP launch ends on its logo alone, though its post carries a docs link. LexnLin and Claude end on their own first frame, so the autoplay loop is seamless. The top launch films sit near -9 LUFS, supermemory's at -11.6 to -16.1, and Keiki at -34.9, which is effectively silent; it's unclear whether X normalises loudness, so check by ear on a phone.
