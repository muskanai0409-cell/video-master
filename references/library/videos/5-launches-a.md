- **Lessons for her launch films:**
  1. Name the product and state the claim by 1.5s with typed text on a plain ground, and bring a proof object in by 3s (partner logos, star count, price).
  2. Build the middle on one task shown end to end (prompt at readable or giant size → visible work → structured result), then run the extras at ~1s per card. Exa does this in 23s.
  3. Give invisible work its own lane or counter on screen. For supermemory, that means a memory lane beside the chat logging each write and recall, like OpenAI's backend lane or Monid's $0.00 counter.
  4. For memory, script the human moment of being remembered ("Wait, you remember that?", "I know you like visuals"), then show the stored memory as a readable object, as Perplexity does with its memory page.
  5. Use one fixed template for features (label pill plus one proof card, same position, 2–4s each) and close the run with "…and N more".
  6. Keep the frame moving with pushes, crops and morphs rather than cuts, and save one burst of 0.1–0.5s cuts for the montage just before the reveal (Academy, GTE).
  7. End with a 3–5s hold on a CTA in the product's own language: a button, a paste-into-your-agent command in a terminal pill, or a QR code plus URL.
  8. Mark a change of point of view with a ground or theme switch (X Numbers: light is you, dark is the other person; ToneBird: a vintage frame for "before").
