# Recipe: product demo

A film of the product doing one real job: a capture, a rebuilt UI or a live object. It runs 10 to 90s and is the second most common format in her bookmarks (27 of 156).

**Use it when** the product itself is the proof.

**Variants:**
- one-task demo (the default);
- agent-native install;
- result first, receipts after;
- one-take loop.

**On supermemory** rebuild the UI in vector from the measured DOM; never upscale a screen recording (her 2026-10-05 rule). Give memory its own lane (see `memory-scenes.md`).

## Beat template: one-task demo, about 23s (after 5#18)

| Time | Beat | What happens |
|---|---|---|
| 0 to 2.5s | Claim and entry | "X is now in Y" types on; the key word is selected and clicked, and the click drops you into the product (5#18). Or the app icon is clicked and scales up into the window (5#14) |
| 3 to 5s | The ask | One real, hard prompt typed at readable or giant size, as if the camera sits inside the input (5#14) |
| 6 to 11s | The work, visible | Status lines stacking ("Web search…" seven times), then a scale moment: "12 subagents reviewed companies" over a wall of scrolling source URLs (5#18). Or a lane, a counter or named cursors |
| 12 to 16s | The result | A structured answer (a table, a diff, a card) floated on the ground, cropped so its key line reads, with one number or word in the accent |
| 16 to 18s | Extras or bookend | A ~1s-per-card run of secondary features (5#14), or the opening line returning as "X is available in Y" |
| 18 to 23s | End | The URL typed into a pill, or the logo held 4 to 5s |

## Variant: agent-native install

Show the install literally. For a developer audience, this is the product demo.
- **One URL in a connector field (6#8):**
  - a 1s co-brand card, then the founders;
  - the real connector settings with the remote MCP URL pasted at about 5s;
  - "Hey" typed, tools found, deliverables scrolling;
  - lists scrolled to prove "100+ skills" and "3000 integrations";
  - "Try it on Claude today:" plus the URL;
  - a lockup that mirrors the opening.
- **⌘V into a coding agent (6#14):**
  - the docs page with the URL bar highlighted;
  - ⌘V keycaps over the agent's prompt box;
  - "Working for 2m 18s";
  - a "Done" summary with the changed files;
  - the live result in the product it touched;
  - the install command in the end card.
- **One command, twice (6#9):** a terminal pill with the SKILL.md setup command at about 15s and again at the end.

## Variant: result first, receipts after

- Open on the finished output already moving, then rewind through the intermediate steps and end on the rawest one (6#16: page, then image, then mesh).
- A receipt inset of the input beside the output proves the claim without words (6#3: the listing photo next to the walkable room).
- A finished artifact that moves from frame 0 can carry a demo with no edit or voice (5#15: a rotating 3D ankle atlas, 1.0M views).

## Variant: one-take loop (10 to 45s)

- A one-click layout morph opens it: a tree flies into a force graph (6#17). Or a grid of parallel live agent runs with labelled cursor pills (6#10, a 10s loop).
- It ends in its start state, so autoplay rewatches seamlessly. No end card.

## Moves that make it

- **Crop to the panel that matters.** Push in until the line or control fills the frame; never show the whole desktop.
- **One caption, one action:** each caption pairs with exactly one on-screen action, so a 90s walkthrough reads as a guided tour (5#6).
- **In-scene output, then one cut to the log that proves it:** the model writes "GPT LIVE 1" onto an LED display on the desk, and the backend lane shows the call (5#2).
- **Prove a number by scrolling the real list,** rather than stating a count (6#8).
- **The cursor carries the story:** select, click, ⌘V, Allow.
- **Output becomes the logo:** zoom into what the product just produced and let it resolve into the end mark (5#6).
- **Float the window on a designed or lit stage** to lift a plain capture (6#16).

## Ending

- The URL typed into a pill beside the product name and platforms ("macOS & Windows (Beta)", 5#14).
- The install command as the end card: "muse plugins install …" in blue mono (2#21).
- Logo only, held 4 to 5s (5#18, 5#6).
- Loops and raw captures can stop with no card.

## Pitfalls

- A static full-desktop capture: 6#23 measures 26% moving and 6#15 11.5%. The eye has nothing to do.
- A raw 4K recording with tiny text (3#16, 3#19, 3#22): unreadable at phone size.
- A demo with no task: features shown without a job to do read as a tour, not proof.
- Sample data shown as if it were real: label it on screen, as 6#8 does.

## Build it here

- Rebuild the product UI in vector from the live page's measured DOM. `engine/console-film/` is the worked example: a console card, a typeset terminal, cursor clicks with ripples, and the brand film behind.
